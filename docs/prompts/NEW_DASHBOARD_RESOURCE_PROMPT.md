# Add a dashboard resource

Add its independent metadata/domain models, transport mapping, and dashboard service request. Define a query key and render loading/error/empty/data states using shared primitives. Add the same resource to the demo model registry and compute record counts from current authorized state after mutations. Dashboard authorization belongs to the backend and demo API. User-facing model and field labels belong in strings or backend-provided display metadata. Update [BACKEND_CONTRACT.md](../BACKEND_CONTRACT.md).
